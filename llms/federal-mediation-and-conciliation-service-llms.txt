# Federal Mediation and Conciliation Service (FMCS)

> An independent United States federal agency that provides mediation, arbitration referral, facilitation
> and conflict-resolution services for labor-management relationships. FMCS publishes no developer
> programme and no API documentation. It does serve a real, anonymous, read-only WordPress REST API at
> https://www.fmcs.gov/wp-json — 31 confirmed public operations over the agency's pages, posts, document
> library, neutrals directory, training events and service taxonomy.
>
> GENERATED BY API EVANGELIST, NOT BY FMCS. FMCS serves no /llms.txt of its own (probed 2026-09-09:
> https://www.fmcs.gov/llms.txt returned HTTP 404). Everything below was fetched, probed or derived from
> the agency's own public surface and is dated.

## What FMCS actually publishes

- [FMCS website](https://www.fmcs.gov/): the agency's site, on WordPress.
- [Services](https://www.fmcs.gov/services/): collective bargaining mediation, grievance mediation,
  arbitration referral, facilitation, dispute-resolution systems design, regulatory negotiations.
- [Documents and Data](https://www.fmcs.gov/resources/documents-and-data/): the real data programme.
  Monthly F-7 collective bargaining notice workbooks (.xlsx, FY2018 to present), FOIA logs and annual
  reports (PDF + XML + CSV), arbitrator per-diem rate sheets, financial audit reports.
- [Data](https://www.fmcs.gov/data/): the Evidence Act page — names a Chief Data Officer and data@fmcs.gov.
- [Forms and Applications](https://www.fmcs.gov/resources/forms-applications/): the F-7 notice and the
  arbitration panel request. Since 5 April 2022 F-7 notices may ONLY be filed through the online portal.
- [Vulnerability Disclosure Policy](https://www.fmcs.gov/vulnerability-disclosure-policy/): a complete
  CISA BOD 20-01-style policy naming security@fmcs.gov and a 90-day coordinated disclosure window.
- [FMCS Arbitration System](https://arbitration.fmcs.gov/): login-gated case system. No public contract.

## The API (derived, not published by FMCS)

- Base URL: https://www.fmcs.gov/wp-json — anonymous, no key, no signup, no rate limit signalling.
- [Derived OpenAPI 3.1.0](https://raw.githubusercontent.com/api-evangelist/federal-mediation-and-conciliation-service/refs/heads/main/openapi/federal-mediation-and-conciliation-service-wp-content-openapi.yml) — 31 operations, every one confirmed
  HTTP 200 unauthenticated on 2026-09-09.
- [Verbatim route discovery document](https://raw.githubusercontent.com/api-evangelist/federal-mediation-and-conciliation-service/refs/heads/main/openapi/federal-mediation-and-conciliation-service-wp-routes-original.json) — the 1,020-route index
  FMCS's WordPress serves; the source this spec was derived from.
- Most useful collections: `/wp/v2/media` (1,122 documents — the F-7 workbooks live here),
  `/wp/v2/pages` (117 programme pages), `/wp/v2/faq_category` (the 17-term FMCS service taxonomy),
  `/wp/v2/search` (cross-type search), `/wp/v2/event` (training).
- Pagination: `page` + `per_page` (max 100), totals in `X-WP-Total` / `X-WP-TotalPages`, RFC 8288
  `Link` for next/prev. Change signal: `modified_gmt` and `modified_after`; there is no ETag.
- Errors are the WordPress envelope `{code, message, data.status}` — NOT RFC 9457 problem+json.

## What does not exist

Probed on 2026-09-09 and confirmed absent: no OpenAPI or Swagger published by FMCS, no GraphQL, no MCP
server, no A2A agent card, no AsyncAPI, no webhooks, no gRPC, no WSDL, no /.well-known/security.txt,
no /apis.json, no llms.txt, no developer portal, no api./data./developer. subdomain, no status page,
no changelog, no SDKs, no CLI, no sandbox, no Postman collection, no OAuth scopes.

Personal data note: two working operations (`/wp/v2/wpbdp_listing`, `/wp/v2/users`) return records
identifying named individuals. They are documented in the spec and deliberately excluded from every agent
skill and MCP tool in this profile; no example responses for them are stored.
